# SHAU & HOT DOGS

Веб-приложение для заказа хот-догов, шаурмы и снеков.

## Стек

- React
- TypeScript
- Redux Toolkit
- Axios
- SCSS
- Font Awesome

## Возможности

- Каталог товаров по категориям (хот-доги, шаурма, шаурма-боксы, десерты, салаты, снеки)
- Выбор размера порции
- Корзина
- Поиск

## Демо

[https://dmpe91.github.io/hot_dog/](https://dmpe91.github.io/hot_dog/)

## Запуск

```bash
git clone git@github.com:DmPe91/hot_dog.git
cd hot_dog
npm install
npm start
```

## Деплой

```bash
npm run deploy
```
